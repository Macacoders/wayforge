# Runtime Compatibility Matrix

Date: 2026-10-26

Scope: wayforge installs content once into `.agents/` and reaches each runtime through runtime-specific directory pointers or generated config paths (ADR-0046). `verified` means the artifact was exercised against the named runtime version on this host. `pending` means the implementation is in place but has not been exercised on the required environment. `n/a` means the runtime does not consume that artifact format.

| Artifact | OpenCode 1.18.35 | Kilo Code 7.8.17 | Pi |
| --- | --- | --- | --- |
| Agents | verified — `.opencode/agents` points at `../.agents/agents`; `opencode agent list` shows `planner`, `delivery`, `troubleshooter`, `research`, `code`, `architect` | verified — `.kilo/agents` points at `../.agents/agents`; `kilo agent list` shows the same six agents | n/a — Pi does not load OpenCode agent definitions |
| Commands | verified — `.opencode/commands` points at `../.agents/commands`; `opencode debug config` exposes all 15 wayforge commands | verified — `.kilo/commands` points at `../.agents/commands`; `kilo debug config` exposes all 15 wayforge commands | n/a — Pi does not load OpenCode command definitions |
| Skills | verified — generated `"skills": ["./.agents/skills"]`; `opencode debug skill` lists the wayforge skills | verified — the same generated config shape; `kilo debug skill` lists the wayforge skills | verified — Pi discovers `.agents/skills/<name>/SKILL.md` natively, with no installer pointer or config entry |
| Plugins | verified — generated `"plugin": ["./.agents/plugins/ponytail/ponytail.mjs"]`; `opencode debug config` resolves it to a `file://` plugin origin | verified — the same generated `plugin` entry; `kilo debug config` resolves the ponytail plugin alongside Kilo's built-in plugins | n/a — Pi does not consume OpenCode plugin modules |

## Pointer mechanism

| Environment | Mechanism | Status |
| --- | --- | --- |
| Linux / macOS | relative directory symlink (keeps the repository relocatable) | verified |
| Windows | directory junction fallback with an absolute target; the pointer does not survive moving the repository | pending — no Windows host available on the verification host |
| Symlinks and junctions unavailable | generated stub files (copy `.agents/` content into the native directory) | deferred — not implemented (ADR-0046 decision 6) |

Per-runtime materialization of the `.agents/` tree into native runtime directories is future work; the supported design is pointers plus generated config paths.

## Verification notes

Verified on 2026-10-26 with scratch installs from this checkout:

```bash
# OpenCode
npx tsx cli/src/index.ts install --repo /tmp/wfg-matrix-oc --providers openai --runtime opencode --no-track --skip-node-check
cd /tmp/wfg-matrix-oc
opencode agent list
OPENCODE_DISABLE_EXTERNAL_SKILLS=1 opencode debug skill
opencode debug config

# Kilo Code
npx tsx cli/src/index.ts install --repo /tmp/wfg-matrix-kilo --providers openai --runtime kilocode --no-track --skip-node-check
cd /tmp/wfg-matrix-kilo
npx --yes @kilocode/cli@7.8.17 agent list
npx --yes @kilocode/cli@7.8.17 debug skill
npx --yes @kilocode/cli@7.8.17 debug config
```

Pi evidence: this repository's active Pi session discovers its skills from `.agents/skills/<name>/SKILL.md`; Pi needs no installer output for skills. Pi has no equivalent loader for OpenCode agent, command, or plugin definitions.

Kilo's `.kilo/.gitignore` is generated by Kilo itself; wayforge only manages the `.kilo/agents` and `.kilo/commands` pointers and does not blanket-ignore `.kilo/`.
