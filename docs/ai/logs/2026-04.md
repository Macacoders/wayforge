# AI Change Log: 2026-04

## 2026-04-29

- Started migration from a multi-runtime AI configuration repository to an OpenCode-only, OpenAI-only workflow.
- Defined `planner`, `code`, and `test` agent responsibilities.
- Adopted progressive disclosure for agent context management.
- Added durable AI memory structure under `docs/ai/`.
- Replaced the installer with project-local OpenCode symlinks.
- Removed the old VS Code Copilot adapters, generic roles, broad skills, and profile templates.
- Validated shell syntax, OpenCode JSON syntax, dry-run installation, real symlink installation, symlink refresh with `--force`, and preservation of existing non-symlink files.
- Tuned `code` to use medium reasoning effort and low temperature for more conservative implementation behavior.
- Updated the lightweight OpenCode model to `openai/gpt-5.4-mini-fast` based on the OpenAI models exposed by `/models`.
- Added `research` as an onboarding subagent for existing repositories and `/onboard-repo` to create or propose initial `docs/ai/` memory before implementation planning.
- Renamed the custom primary planning agent to `planner` to avoid colliding with OpenCode's native `plan` agent in `/agents`.
- Set OpenAI `gpt-5.5` and `gpt-5.5-fast` provider options to high reasoning by default; `code` still overrides its agent reasoning to medium.
