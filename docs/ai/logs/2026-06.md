### Session notes — tooling pitfalls (issue #118 handoff)

- `gh-issue.ts` has no `view` subcommand. Use `gh issue view <number>` with `GITHUB_TOKEN` set for full issue details (body, comments, timeline).
- Type-checking with `strict: true` requires both `typescript` and `@types/node` installed. From this repo root: `npx --yes -p typescript -p @types/node -- tsc --noEmit`. Check `node_modules/@types/node` health first before workarounds.
