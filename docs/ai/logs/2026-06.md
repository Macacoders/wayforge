## 2026-06-15

- Changed default provider from `openai` to `free-tier` for opencode runtime in all four installer scripts (`bootstrap.sh`, `bootstrap.ps1`, `bootstrap-interactive.sh`, `bootstrap-interactive.ps1`). Added `free-tier` as a recognized provider value with `Validate-FreeTierRuntime` / `validate_free_tier_runtime` guard (only available for opencode, not kilocode). Free-tier installs produce empty model strings and no agent block — no external provider configuration required. Replaced `balanced-default-agent-block.jsonc` with `balanced-openai-only-agent-block.jsonc` for single-provider OpenAI installs. Updated `README.md` and `architecture.md` to document free-tier as the new default.
- Completed issue #45 (token-counter plugin): implemented a `count_tokens` OpenCode plugin tool under `base/opencode/plugins/token-counter/` using `gpt-tokenizer` with `cl100k_base` encoding. Spike evaluated `js-tiktoken`, `tiktoken`, and `gpt-tokenizer` (all perfectly accurate; `gpt-tokenizer` chosen for pure-JS portability). ADR-0011 records the tokenizer selection. Installer scripts updated to propagate `base/opencode/plugins/` → `.opencode/plugins/`. Plugin registered in `opencode.jsonc`. Architecture updated: `.opencode/plugins/**` now recognized as a managed directory. Follow-on handoff created for session-level token consumption tracker (distinct from file-counting).
- Completed session-level token tracker plugin (`base/opencode/plugins/session-tracker/`): spike confirmed that the OpenCode SDK exposes provider-reported token consumption via the `event` hook (`session.next.step.started` / `session.next.step.ended` events with `tokens { input, output, reasoning, cache }` and `cost`). Plugin accumulates per-agent token totals, per-tool invocation counts, and per-command invocation counts in-memory, exposed via `token_summary` tool. Registered alongside `token-counter` in `opencode.jsonc` plugin array. No installer changes needed (auto-propagated).
