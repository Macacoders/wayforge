# AI Change Log: 2026-08

## 2026-08-19

- Removed DeepSeek from the opencode-go distribution (inaccessible outside China; ADR-0032). New defaults: main `minimax-m2.7` (planner/delivery/config default), small/quickcode/fast preset `kimi-k2.7-code`. ## 2026-08-06

- Completed Windows/Linux parity fixes (plan `docs/ai/plans/2026-08-06-windows-crlf-parity.md`). Phase 1: prettier `endOfLine: auto`, `readFragment` CRLF→LF normalization (fixes mixed-EOL generated `opencode.jsonc` + comma-newline test), symlink tests gated behind a capability probe; installed missing vitest via `npm install`. Phase 2: exported `posixPath` from `manifest.ts` and normalized the four install discovery loops, eliminating phantom "new managed path discovered" logs and redundant re-copies on Windows refresh. Verified e2e: refresh logs zero phantom lines, manifest byte-stable, 8/8 agents get `permission:` frontmatter. Created ADR-0031.
- Pre-existing fixes from same effort (uncommitted, prior to plan): CRLF-strip in `renderAgentWithCentralPermissions` (permissions now injected into CRLF frontmatter) and `path.resolve(options.repo)` in install (relative `--repo` no longer corrupts `.ai-config-managed`).
- Known pre-existing issues (not fixed): 12 gh-issue E2E auth failures on Windows (environment-gated, needs GitHub credentials); `cli/src/lib/tracking.ts` prettier printWidth debt fails `make check-node` at HEAD on Linux too; `npm audit` 2 high-severity vulns.
