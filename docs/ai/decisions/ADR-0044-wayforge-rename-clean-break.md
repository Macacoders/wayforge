# ADR-0044: Wayforge Rename (Clean Break)

Date: 2026-10-15
Status: Accepted

## Context

The project known as `ai-config` is renamed to `wayforge` ahead of the v1.0.0 release. The rename also changes the user-typed CLI command to `wfg` and the GitHub repository to `Macacoders/wayforge`. It is a cross-cutting identity change spanning the CLI runtime, the one-shot installers, the release pipeline, the documentation, and the templates shipped into consumer repositories.

The rename changes externally observable contracts: the managed-marker filename and header, environment-variable names, the install prefix/layout, release-artifact names, and the repository location. This ADR records the decision and its clean-break posture.

## Decision

1. Project identity renames `ai-config` → `wayforge`; the user-typed command renames `ai-config` → `wfg`; the npm packages become `wayforge` (root) and `wayforge-cli` (CLI); the repository becomes `Macacoders/wayforge`.

2. On-disk and interface contracts change outright:
   - Managed marker `.ai-config-managed` → `.wayforge-managed` (plus the `<file>.wayforge-managed` sidecar and the `.wayforge-managed.tmp` temp file); header `// Generated by ai-config bootstrap` → `// Generated by wayforge bootstrap`; sidecar value `generated-by=ai-config-bootstrap` → `generated-by=wayforge-bootstrap`; manifest header `# Generated by ai-config v…` → `# Generated by wayforge v…`.
   - Environment variables `AI_CONFIG_HOME` → `WAYFORGE_HOME`, `AI_CONFIG_VERSION` → `WAYFORGE_VERSION`, `AI_CONFIG_INSTALL_DIR` → `WAYFORGE_INSTALL_DIR`, `AI_CONFIG_NODE_BASE_URL` → `WAYFORGE_NODE_BASE_URL`.
   - Install prefix `~/.ai-config` / `%LOCALAPPDATA%\ai-config` → `~/.wayforge` / `%LOCALAPPDATA%\wayforge`; share directory `share/ai-config` → `share/wayforge`; installed binary `bin/ai-config[.exe]` → `bin/wfg[.exe]`.
   - Log/banner prefix `[ai-config]` → `[wayforge]`; temp-directory prefix `ai-config-` → `wayforge-`.

3. Installer and release surface:
   - `REPO` `Macacoders/ai-config` → `Macacoders/wayforge`; release artifacts `ai-config-<os>-<arch>` → `wayforge-<os>-<arch>` and `ai-config-share-<v>.tar.gz` / `.zip` → `wayforge-share-<v>.tar.gz` / `.zip`.
   - Bash PATH marker `# >>> ai-config >>>` / `# <<< ai-config <<<` → `# >>> wayforge >>>` / `# <<< wayforge <<<`.
   - PowerShell functions `Install-AiConfig` / `Uninstall-AiConfig` → `Install-Wayforge` / `Uninstall-Wayforge`.
   - The compiled binary's version is injected via `--define process.env.WAYFORGE_VERSION` (Makefile and release workflow), matching the CLI's `WAYFORGE_VERSION` read.
   - Snippet helpers `_ai_config_root`, `ai-setup-repo*`, `ai-uninstall-repo*` → `_wayforge_root`, `wayforge-setup-repo*`, `wayforge-uninstall-repo*`.

4. This is a **clean break**: no migration readers, aliases, or shims. It supersedes ADR-0009's backward-compatibility/transition clauses and the now-stale naming in ADR-0032 and ADR-0035; the underlying mechanism decisions of those ADRs remain in force.

5. `installed-projects.json` adopts the `wayforgeVersion` field and relocates with the prefix (`~/.wayforge/installed-projects.json`). Pre-rename tracking state is abandoned, not migrated.

## Alternatives considered

- **(a) Clean break (chosen):** pre-v1.0 timing and a small installed base make the compatibility cost unjustified.
- **(b) Dual-read compatibility** (read both marker sets/fields for one major version): ongoing dual maintenance and complexity for a small user base.
- **(c) Migration command (`wfg migrate`):** extra surface to build, document, and test; not warranted pre-1.0.

## Consequences

- Pre-rename installs are abandoned: existing consumer repos keep stale `.ai-config-managed*` markers, `~/.ai-config` / `%LOCALAPPDATA%\ai-config` prefixes, `bin/ai-config[.exe]`, and old `# >>> ai-config >>>` PATH blocks. The new CLI neither reads nor cleans them.
- The frozen legacy installers (`install/legacy/**`) can no longer locate TS-installed projects at all, because the manifest filename changed — a wider break than ADR-0033's format-only interop gap.
- The `AI_CONFIG_*` environment variables are dropped without an alias; the frozen `install/legacy/bootstrap-thin.*` still export `AI_CONFIG_HOME`, which is now ignored.
- Operational ordering: the GitHub repository must be renamed to `Macacoders/wayforge` before (or with) a release, and no release should be cut between the CLI rename and the installer/release-pipeline rename.
- Historical prose (plan/ADR/log/report documents, frozen legacy scripts, and the pre-rename CHANGELOG entry) is intentionally left unchanged.

## Related

- Supersedes the backward-compatibility/transition clauses of ADR-0009 (unified project-level managed file format).
- Renders the naming in ADR-0032 (runtime source-dir resolution) and ADR-0035 (one-shot CLI installer) stale; their mechanism decisions remain in force.
- Extends the accepted interop break of ADR-0033 (legacy installer deprecation) from format to filename.
