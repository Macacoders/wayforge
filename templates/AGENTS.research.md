# AGENTS.md (Research Profile)

## Mission

Produce technically sound, reproducible research outputs with explicit assumptions, datasets, and evaluation criteria.

## Setup checklist

1. Confirm environment and dataset paths.
2. Record baseline metrics before changes.
3. Define acceptance criteria for each experiment.
4. Use runbooks for repeatability.

## Research style rules

- State hypotheses before running experiments.
- Keep experiment logs structured and timestamped.
- Separate observation from interpretation.
- Track threats to validity.

## Validation rules

- Re-run key experiments at least once.
- Include confidence intervals or variation notes when possible.
- Note missing controls and unresolved confounders.

## Definition of done

- Claims are evidence-backed.
- Runs are reproducible from commands and config.
- Metrics are summarized with caveats.
- Next experiments are prioritized.
