Generate a ponytail impact scoreboard from git history and current state.

$ARGUMENTS

Analyze the repository for measurable ponytail impact:
- Lines of code avoided (count `ponytail:` comments and estimate savings)
- Token cost reduction (fewer lines = fewer tokens per session)
- Speed improvement (simpler code = faster iteration)

If git history is available, compare before/after metrics. Produce a concise scoreboard with concrete numbers where possible. Use conservative estimates; do not fabricate data. Flag areas where ponytail discipline has had the most measurable impact.
