# Metadata
# Constraints
- [ ] No fabrication of citations or contributions
- [ ] Lead with contribution and novelty alignment
- [ ] Maintain consistent terminology
- [ ] Use British English spelling

# Procedure
- [ ] **Assessment**
  - [ ] Identify discovery root and runner
  - [ ] Map claims to evidence status
  - [ ] Group by theme; prioritize novelty diff
- [ ] **Compression**
  - [ ] Reduce paragraphs to claim-evidence-implication
  - [ ] Avoid fluff/adjectives; prefer technical terms
  - [ ] align with target venue expectations
- [ ] **Validation**
  - [ ] verify citation accuracy and coverage
  - [ ] Ensure flow across related-work sections
  - [ ] Track unsupported claims for follow-up
