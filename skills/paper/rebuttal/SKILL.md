# Metadata
# Constraints
- [ ] No confrontational tones; stay evidence-first
- [ ] No unaddressed reviewer concerns
- [ ] Use British English
- [ ] Maintain consistent author voice

# Procedure
- [ ] **Assessment**
  - [ ] Consolidate reviewer feedback; group by theme
  - [ ] Identify critical blockers vs polite suggestions
  - [ ] Map concerns to existing/new evidence
- [ ] **Drafting**
  - [ ] Start with high-level summary of revisions
  - [ ] Detail point-by-point responses (evidence-first)
  - [ ] Match reviewer depth/technicality
- [ ] **Refinement**
  - [ ] Validate claim-evidence alignment
  - [ ] Ensure consistent and professional tone
  - [ ] Review for brevity and clarity
- [ ] **Follow-up**
  - [ ] Highlight most significant changes made
  - [ ] Track unaddressed points for discussion
