# Metadata
# Constraints
- [ ] No overclaimed unsupported findings
- [ ] No bold/italic markers in prose (except titles)
- [ ] Use British English throughout
- [ ] Maintain consistent author voice and terminology

# Procedure
- [ ] **Drafting**
  - [ ] Start by defining contribution, novelty, and scope
  - [ ] Structure: claim–evidence–implication per paragraph
  - [ ] Prefer numbers over adjectives; keep flow explicit
- [ ] **Review**
  - [ ] Align abstract, intro, and conclusions
  - [ ] Track open claims needing proof or citation
  - [ ] Propose two rewrite options when stuck
- [ ] **Maturity**
  - [ ] Validate logic and evidence alignment
  - [ ] Mark unsupported statements with TODO tags
  - [ ] Finalise technical language and flow
